# 脱敏与真实性边界

## 公开仓库包含

- 根据原始业务规则重构的通用化代码；
- 完全合成的目录、桩号、文件名和占位图片；
- 由合成数据生成的 Excel/TXT 示例；
- 面向作品集展示的流程说明和测试。

## 公开仓库不包含

- 真实工程名称、单位名称、人员姓名、群聊名称；
- 真实工程照片、桩号、原始 Excel/PDF；
- 本机用户名、绝对路径或原脚本的历史 Git 记录；
- 能够反推出具体项目的信息或原始文件元数据。

## 真实性表述

可以确认该工具完成过一次实际数据运行和项目内结果提交。公开材料不将其描述为正式生产系统、商业化产品或经大规模用户验证的解决方案。

## 功能边界

本工具只读取文件名和目录结构：

- ✓ 表示检索到符合规则的照片；
- ✗ 表示未检索到，需要人工复核；
- 不识别照片画面内容；
- 不判断工序是否真实完成；
- 不判断施工质量或验收是否合格。

## AI 辅助说明

原项目与公开演示版均使用了 AI 辅助开发。项目作者负责业务问题识别、规则定义、结果核验、边界判断与交付整理。
