# 脱敏演示数据

本目录只用于公开演示，不包含任何真实工程照片、桩号、项目名称或人员信息。

运行：

```bash
python scripts/create_demo_data.py
python pile_photo_checker.py examples/demo_input --output examples/demo_output
```

合成样例会生成 22 张占位图片，并覆盖以下规则：

- `P001`：7 个标准工序均可识别；
- `P002`：缺少“入岩”，包含一个会归入“其它”的文件名；
- `P003` 与 `P003D900`：用于验证 `D` 后缀桩号合并；
- `钢筋笼焊接`：用于验证其归一为“焊接”；
- `现场照片.png`：不符合命名规则，进入“命名异常”清单。

预期统计：扫描 22 张、成功解析 21 张、命名异常 1 张、形成 3 个桩号分组。
